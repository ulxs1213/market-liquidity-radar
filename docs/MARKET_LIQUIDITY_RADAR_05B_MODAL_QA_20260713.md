# 05B 完整成交终端弹窗：实现与验收（2026-07-13）

## 功能范围

以下可识别目标均支持双击打开 05B：

- 01 头部板块热力图中的任一板块；
- 02 净流入/净流出排行中的任一板块；
- 03 资金赛马曲线及右侧任一板块按钮；
- 04 核心个股热力图中的任一个股；
- 05 全市场流动性散点图及三组重点队列中的任一个股。

板块双击流程为：先完成原有板块联动和核心股查询，再按成交额选择该板块第一只可用核心股，读取其 05B 数据并打开弹窗。板块没有可用核心股时才回退到当前已选标的；完全没有可路由标的时显示明确提示，不打开带旧股票数据的空白弹窗。

## 复用方式

- 原页面只有一个 `#stockTerminalWorkspace`。
- Workspace 包含 05B 标题、数据时间、集合竞价控制、价格/均价/成交量/资金流图、图表来源说明和实时五档盘口。
- 打开弹窗时使用 `appendChild` 把同一个 Workspace 移入 `#stockTerminalModalMount`；关闭时再移回 `#stockTerminalHome`。
- 不使用 `cloneNode` 或 HTML 复制，因此所有 DOM ID、ECharts 实例和后续 crosshair/axisPointer 状态始终只有一份。
- 弹窗中的“再次弹窗”按钮会隐藏，避免递归打开。

## 关闭、状态与无障碍

- 明确关闭按钮、`Esc` 和点击遮罩空白处都调用同一恢复流程。
- 打开前记录页面 `scrollY` 和触发元素；关闭且模块重新打包后恢复页面位置与焦点。
- 模态层使用原生 `<dialog>`，声明 `role=dialog`、`aria-modal=true`、`aria-labelledby` 和 `aria-describedby`。
- 打开后焦点进入关闭按钮；Tab/Shift+Tab 在弹窗可聚焦控件之间循环。
- 图表增加可聚焦入口；排行和队列目标使用 `role=button`、`tabindex=0`。Enter 与双击执行同一路由。
- 移动 Workspace 不重建图表、不清除本地布局、回放、主题、板块或个股状态。

## 浏览器交叉验收

- 依次双击 01、02、03 的板块，确认 04 先联动且弹窗股票属于该板块核心股。
- 依次双击 04、05 和三个重点队列的个股，确认弹窗标题、图表和盘口均切到对应代码。
- 确认弹窗包含集合竞价控制、完整价格/均价/量/资金图、来源说明及五档盘口，而非简化副本。
- 检查页面任意 ID 均没有重复，弹窗打开和关闭后 ECharts 仍可继续 hover/crosshair。
- 分别使用关闭按钮、Esc、点击遮罩关闭；确认页面回到原滚动位置，触发元素重新获得焦点。
- 在弹窗内反复 Tab/Shift+Tab，确认焦点不逃到背景页面。
- 打开前调整模块大小并滚动页面，关闭后确认模块尺寸、回放状态、主题和滚动位置未丢失。
