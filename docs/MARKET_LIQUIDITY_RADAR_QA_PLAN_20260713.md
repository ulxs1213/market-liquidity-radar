# 市场流动性雷达 2026-07-13 改版测试计划

## 执行原则

1. 每一项功能由一个 Agent 实现。
2. 实现者先完成单元/静态/接口自测。
3. 另一名 Agent 使用不同测试方法交叉验证，不以实现者自测代替。
4. 分项全部通过后，由主 Agent 在 8772 真实页面从上到下连续测试。
5. 任何交叉测试失败都退回对应实现 Agent；修复后重新执行该分项与受影响的整体验收。

## 数据口径提醒

- `fflow/kline` 提供供应商估算的主力净流及不同单量级净流，不提供交易所审计的逐账户总流入/总流出。
- 05B 可以从相邻累计净流计算“本分钟净流变化”；正值标为“本分钟净流入”，负值标为“本分钟净流出”，不得表述为总买入或总卖出金额。
- 历史五档盘口无法由分钟行情回补；历史回放时盘口必须显示为“当前快照”或“历史不可回放”。
