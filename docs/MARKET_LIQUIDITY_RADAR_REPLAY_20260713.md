# 市场流动性雷达：本地历史分钟回放契约

更新日期：2026-07-13
适用页面：`http://127.0.0.1:8772/market-liquidity-radar`

## 1. 功能目标

历史回放不是把当天最终截面贴上“历史”标签，而是按 8772 在盘中实际保存的分钟横截面逐帧重建页面。选择交易日并载入后，可播放、暂停、切换 1×/2×/5×、拖动进度滑杆、查看当前回放时间并一键回到实时。

每个回放帧同时驱动：

- 01 头部板块热力图；
- 02A/02B 净流入与净流出榜及截至该帧的迷你轨迹；
- 03 多板块资金赛马，横截面 TOP 选择和曲线终点都严格截止当前帧；
- 04 选中板块核心个股（仅使用该分钟实际留档的行业/概念分类）；
- 05 全市场流动性核心标的与三类队列。

## 2. 数据源与不可伪造边界

唯一回放事实库为：

`data/market_heatmap/market_heatmap_intraday.sqlite3`

使用两张分钟表：

| 表 | 回放内容 | 主键口径 |
| --- | --- | --- |
| `sector_intraday` | 行业/概念板块价格、涨跌幅、成交额、f62 主力净流入、广度、强弱分 | 板块类型 + 代码 + 行情时间 |
| `stock_intraday` | 当时进入全市场流动性采集池的股票、成交额、涨跌幅、量比、f62、行业和概念分类 | 股票代码 + 行情时间 |

约束：

1. 每一步只读取一个精确存在的分钟桶，不用上一分钟截面前向填充。
2. 服务未运行、上游失败、午休或落盘失败形成的分钟缺口不会插值。
3. 旧数据库升级前没有保存股票行业/概念字段时，04 核心个股明确留空；不能用当前板块成分冒充历史成分。
4. 05 只代表当时进入本机流动性 TOP 采集池的股票，不声称覆盖当分钟全部 A 股。
5. 资金字段仍是东方财富 `f62` 供应商估算口径，不是交易所逐账户现金流。
6. 回放不提供历史五档盘口；分钟行情不能事后还原委托队列。

## 3. 覆盖率和缺口

载入日期时，页面必须显示：

- 最早和最晚真实留档时间；
- 真实帧数量；
- 板块、个股各自的帧数量；
- 覆盖区间内缺失分钟列表/数量；
- 每帧板块数、个股数以及是否达到该日最大观察覆盖；
- 是否为完整 242 分钟交易日；
- 旧库是否存在可用行业/概念分类。

“完整”只表示本地分钟桶与当日最大代码覆盖一致，不代表外部供应商具有交易所级完整性。

## 4. API

### `GET /api/market_heatmap/replay_manifest`

参数：

- `board_type=industry|concept`
- `trade_date=YYYY-MM-DD`（可选；省略时选择本地最近有板块留档的日期）

返回 `available_dates`、`frames` 和 `coverage`。`frames` 只列真实存在的分钟，不补齐 242 个虚拟帧。

### `GET /api/market_heatmap/replay_frame`

参数：

- `board_type=industry|concept`
- `trade_date=YYYY-MM-DD`
- `frame_time=HH:MM`
- `selected_code=BKxxxx`（可选）
- `top_each=1..500`

返回同一帧联动包：`snapshot`、`race`、`liquidity`、`core_stocks`、`sparklines`、`session_progress` 和 `coverage`。请求不存在的分钟返回错误，不返回临近帧。

## 5. 前端状态机

状态为：

`实时 → 已载入/暂停 → 播放 → 已暂停/到达末帧 → 回到实时`

- 进入回放时清除 3 秒实时刷新定时器。
- 1×/2×/5×分别按约 1000/500/200 毫秒推进一个“真实已观察分钟帧”；速度不是模拟真实一分钟时长。
- 拖动进度条会暂停播放并读取目标真实帧。
- 切换板块、赛马 TOP 或点击板块时重新读取同一帧，保持 01–05 一致。
- API 慢响应通过请求序号丢弃，旧帧不得覆盖用户最新选择。
- 回到实时后清理回放状态、恢复最近日赛马和 3 秒刷新。

## 6. 验收

1. 有 `09:31`、`09:33` 留档但缺 `09:32` 时，清单必须报告 `09:32` 缺口，进度条只含两个可播放帧。
2. 请求 `09:32` 必须失败，并出现“不插值”提示。
3. 播放 `09:31` 时，赛马曲线不得出现 `09:33` 数据。
4. 01、02、03、04、05 的横截面时间必须相同。
5. 行业分类可用时，04 只显示该帧匹配所选行业且当时实际留档的股票。
6. 分类不可用时，04 为空并显示原因。
7. 回放过程中不执行 3 秒实时刷新；回到实时后恢复。
